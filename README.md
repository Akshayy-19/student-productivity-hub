# Student Productivity Hub — StudySpace

StudySpace is a responsive student productivity dashboard for organizing assignments and tracking study progress.

## Features
- Dashboard showing total, pending, completed, and overdue assignments
- Add, edit, complete, and delete assignments
- Subject and priority selection
- Due-date tracking
- Search and filter assignments by status or subject
- Progress summary and task counts by subject
- Customizable student name
- Saves data in the browser with `localStorage`
- Responsive layout for desktop and mobile

## Project files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — assignment management and dashboard behavior

## Run locally
1. Extract the project files.
2. Open `index.html` in a modern web browser.

No build step or package installation is required.

## Note
Assignments and the student name are saved locally in the current browser; they are not synced to a server. Google Fonts are loaded from an external service.
